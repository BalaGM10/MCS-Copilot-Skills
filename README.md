# MCS-Copilot-Skills
A curated collection of reusable **Copilot Studio skills, agents, instructions, and plugins** — built with [Google Antigravity](https://developers.google.com/antigravity) to supercharge your **Microsoft Copilot Studio (MCS)** development experience.

**What Is This?**
Building enterprise-grade Copilot Studio agents means solving the same problems over and over — governance checks, query preprocessing, intent routing, compliance filtering, and more.
**MCS-Copilot-Skills** is a growing library of **drop-in, reusable skills** that solve these common problem spaces so you don't have to reinvent the wheel every time. Each skill is:
- ✅ **Markdown-first** — no heavy dependencies, just prompt templates and reference docs
- ✅ **LLM-agnostic** — works with any model (GPT-4o, Gemini, Claude, local models)
- ✅ **Built with Antigravity** — authored and validated using Google's agentic AI coding assistant
- ✅ **Production-ready** — includes examples, edge cases, and configuration guidance
- ✅ **Composable** — skills can be chained together in pipelines (e.g., classify → enhance → retrieve → respond)
